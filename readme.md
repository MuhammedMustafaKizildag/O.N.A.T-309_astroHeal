# AstroHeal
# This project was used in the NASA SPACE APPS CHALLANGE competition.
AstroHeal is a focused health and wellness web experience designed to make helpful information easier to discover, understand, and use.

## About the project

This repository contains the AstroHeal web application and its static entry point. The project is part of the O.N.A.T initiative and is intended to provide a clear, approachable foundation for health-focused digital experiences.

## Features

- Clean, accessible presentation of health and wellness content
- Responsive experience for desktop and mobile screens
- Lightweight static application structure
- Simple foundation for future features and integrations

## Repository structure

```text
.
├── index.html  # Main application entry point

```

## Running locally

Because the current application is a static site, it can be previewed with any local HTTP server. For example, with Python installed:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

You can also open `index.html` directly, although using a local server more closely matches a deployed web environment.

## Development guidelines

When contributing to AstroHeal:

- Keep the interface responsive and accessible.
- Prefer semantic HTML and clear, maintainable styles.
- Avoid committing secrets, generated files, or unrelated changes.
- Test user-facing changes on both desktop and mobile viewport sizes.
- Keep health-related content clear, responsible, and easy to understand.

## Contributing

1. Create a focused branch from `main`.
2. Make and test your changes locally.
3. Review the rendered experience in a browser.
4. Open a pull request with a concise description of the change and its validation.
